# Bancos publicados

Los archivos de preguntas que se guarden en esta carpeta aparecen en el sitio para todos los usuarios, en el grupo **Publicados** del menú.

## Cómo publicar un banco

1. Descargá la plantilla desde **Gestionar preguntas → Descargar plantilla Excel** y completala.
2. En GitHub, entrá a esta carpeta (`bancos`), elegí **Add file → Upload files**, arrastrá el Excel y confirmá con **Commit changes**.
3. Netlify vuelve a publicar el sitio en uno o dos minutos y el banco aparece en el menú.

- El nombre del archivo es el nombre del banco (por ejemplo, `Parcial 2 - Tomografía.xlsx`).
- Formatos aceptados: `.xlsx`, `.xls`, `.ods` y `.csv` (UTF-8).
- Para corregir un banco, subí de nuevo el archivo con el mismo nombre. Para quitarlo, borralo de esta carpeta.
- El archivo `indice.json` se genera solo al publicar; no hace falta editarlo.
